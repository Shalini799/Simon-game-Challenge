# Simon Game

A browser-based implementation of the classic Simon memory game built using HTML, CSS, JavaScript, and jQuery.

## How It Works

1. The game starts when the user clicks anywhere on the page.
2. The computer generates a random color and flashes the corresponding button.
3. The player must repeat the sequence by clicking the buttons in the correct order.
4. After each successful level, a new color is added to the sequence.
5. The player must remember and reproduce the entire sequence.
6. If the player clicks the wrong button, the game ends and displays "Game Over".

## Features

* Random sequence generation
* Interactive button animations
* Sound effects for each button
* Level tracking
* Real-time answer validation
* Game over detection

## Technologies Used

* HTML
* CSS
* JavaScript
* jQuery
